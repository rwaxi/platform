# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository.

Include the affected contract or component, steps to reproduce, and impact. We aim to acknowledge reports within 3 business days.

## Scope

- Smart contracts under `contracts/`
- Deployment scripts under `scripts/`

Testnet deployments are for demonstration only and hold no real value.

## Keys

No private keys, seeds or API credentials are stored in this repository. Testnet keys used by scripts are generated locally with the Stellar CLI.
